# WS-2 T0: Database Schema Documentation

This document describes the schema applied in T0 for the local TimescaleDB/Postgres instance.

## Overview
We enforce strict WS-1 provenance rules at the schema level using `NOT NULL` constraints to ensure that leaked backtests are structurally impossible.

## Tables

### 1. `forecast_cycles`
Stores information about unique forecast model runs (e.g., NOAA GFS 12z).

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | String | PRIMARY KEY | Unique ID (e.g., `20231231_12z`). |
| `publication_ts` | DateTime | NOT NULL | Wall-clock time the cycle was actually available. |
| `archive_source` | String | NOT NULL | Data source (e.g., `noaa-gfs-bdp-pds`). |
| `model_version` | String | NOT NULL | Version of the model (e.g., `gfs_v16.3`). |

### 2. `signals`
Stores trading signals generated by models.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | Integer | PRIMARY KEY, Auto-Increment | Unique identifier. |
| `timestamp` | DateTime | NOT NULL | The effective time of the signal. |
| `instrument` | String | NOT NULL | Asset to trade. |
| `action` | String | NOT NULL | Action to take (e.g., `LONG`, `FLAT`). |
| `size` | Float | NOT NULL | Position size. |
| `confidence` | Float | NOT NULL | Confidence score `[0, 1]`. |
| `reasoning` | String | | Optional context/metadata. |
| **`forecast_cycle_id`** | String | **NOT NULL** | WS-1 Provenance: Binds to a forecast cycle. |
| **`publication_ts`** | DateTime | **NOT NULL** | WS-1 Provenance: Prevents future-leak. |
| **`archive_source`** | String | **NOT NULL** | WS-1 Provenance: Ensures hash-pinning. |
| **`model_version`** | String | **NOT NULL** | WS-1 Provenance: Prevents model drift. |

### 3. `metrics`
Stores timeseries metrics tracking model performance.

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | Integer | PRIMARY KEY, Auto-Increment | Unique identifier. |
| `timestamp` | DateTime | NOT NULL | Time of the metric observation. |
| `name` | String | NOT NULL | Metric name (e.g., `win_rate`). |
| `value` | Float | NOT NULL | Numeric value. |
| `details` | JSON | | Optional arbitrary structured data. |
